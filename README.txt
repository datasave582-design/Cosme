Vikaasofttech Cosmetics Shop Management — Professional Inventory Edition

Features:
- Password-protected login (default password: 123456, changeable from Settings)
- Fast product entry
- Manual category management
- Inventory filters/search
- Low/out-of-stock and expiry tracking, with expiry shown directly in the Products list
- Expiry quick-filters: All / Expired / Next 7, 15, 30, 60, 90 days
- Stock overview and valuation
- Stock movement history
- Stock adjustment and reorder attention
- Barcode-ready POS billing (USB scanner acts as keyboard input)
- GST, discount, payment method and invoice printing
- Sales history
- Reports with Print + CSV Download
- Product/stock/expiry reports with Print + CSV Download
- Backup and restore JSON
- Responsive mobile and PC UI
- PWA/service worker for HTTPS hosting

GitHub Pages:
Upload the files from this folder to the repository root (not the ZIP). Enable GitHub Pages from Settings > Pages.

Windows PC — Open like real software (not a browser tab):
There are two ways to do this. Way 1 is quickest; Way 2 is best for daily use.

WAY 1 — Double-click START_Vikaasofttech.bat
  This starts a background local server and opens the app in Edge/Chrome
  "app mode" — no address bar, no tabs, just the app window. Nothing to
  install. You must run this file each time you want to open the app.

WAY 2 — Install it as an App (recommended, one-time setup)
  1. Run START_Vikaasofttech.bat once (or open index.html in Edge/Chrome).
  2. In the browser's menu (⋮ or ...), click "Apps" > "Install this site as an app"
     (in Chrome it may say "Install Vikaasofttech...").
  3. This adds a proper icon to your Desktop and Start Menu, like any
     installed Windows program. From then on, just double-click that icon —
     it opens instantly in its own window, with no address bar or tabs,
     and works even without internet.
  4. You no longer need to run the .bat file after this — the installed
     app icon is enough.

Login:
The app opens with a password screen, like a PC desktop program. Default
password is 123456. After logging in, go to Settings > App Password to
change it. The password is stored locally in your browser's database
(IndexedDB), so it stays the same on that device/browser unless you clear
site data. Use the "Lock" button in the top bar to lock the app manually.
